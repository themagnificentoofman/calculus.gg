# Reviewed integration source bundle

This is an offline package of 468 candidates and their independent finite mathematical review evidence. It does not admit records or change the serving bank. The final actual-ID option screen, registry entries, admission and import remain the parent's separate tasks.

The exact union is 350 earlier previews, less 64 superseded previews, plus 152 sign-option repairs, 8 Bessel option revisions and 22 headroom instances. `supersession-ledger.json` identifies every replacement. The unchanged retained baseline is outside this batch, so 468 is not a serving-capacity count.

Use `catalog()`, `build(route, family, index)`, `verify(route, record, index) -> bool`, `reconstruction_evidence(route, family, index)` and `close()` from `runtime.py`. Every route has its own persistent subprocess; builders with common module names never share a Python module namespace. The finite domain comes from the joined reviewed records, not the wider constructor catalogs.

Run `python -B verify_bundle.py` using an environment with SymPy installed. The runtime imports only the copied source closure inside this directory. The original historical repository layout is reproduced under `frozen-repo`, and the worker supplies local environment paths before loading legacy helpers. Preserved fallback strings in byte-exact legacy files are not used. All source copies and generated package assets are hash checked before reconstruction.

`source-joins.json` binds each raw source line and canonical raw hash to its builder, independent review report, original baseline revision or unpublished preview identity, proposed per-index difficulty and normalized lineage. Bessel's eight cases and the ten coupled-endpoint cases have Hard recommendations in this metadata; their original raw bytes remain unchanged. Analytic review is AI-assisted, not human review or formal proof. Runtime reconstruction is a different check from that independent review.

`final-candidates.jsonl` concatenates the selected original raw source lines without modifying candidates. Reports and source history stay frozen. `admission-plan.json` records proposed metadata only; no destination ID or hash is invented. Historical identities appear only where provided by a source or earlier private preview.

To reproduce the package from its original inputs, run `assemble_bundle.py --source-repo PATH --research-root PATH --output PATH`. These explicit input locations are packaging inputs, not runtime dependencies. `copy-manifest.json` retains inspected absolute locations solely as evidence.
