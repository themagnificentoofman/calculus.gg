# Integration quality research bundle

This is an authored, independently checkable candidate bundle. It is not an admission or deployment record. The parent owns blind editorial review, canonical destination identities, registered verification, session testing and release.

The finite catalog has ten proposed topic-local constructions and 108 instances. All new content is independently authored with mathematical references; there are zero source adaptations in this bundle. The earlier two Active Calculus adaptations belong to the separate series pilot and retain their own license contract.

## Portable API

- `integrals.catalog()` returns metadata including an explicit `finiteInstanceIndices` list.
- `integrals.build(family_id, instance_index)` returns a complete raw candidate or rejects indices outside that finite domain.
- `verify_integrals.verify(raw)` returns a report with `status: "passed"`, exact check records, `executedCheckCount`, `sourceContentHash` and analytic-certificate scope. It does not return a Boolean admission decision.
- Runtime dependencies are Python 3 and SymPy, plus the local `common.py`. No machine-specific path or network call is used by these modules.

Copy a frozen bundle to a scratch directory before reproduction, since generation writes its reports. With the desired Python environment active, run `python generate.py`, then `python review_inventory.py`. The second command uses the bundled `option_audit.py`. Strict KaTeX rendering is performed by the parent repository's installed renderer using the separately supplied `render-check.cjs` helper; it is a presentation check, not mathematical proof.

The independent verifier does not import the constructor. Its methods include cyclotomic sign-moment calculation, contour residues, all-pair supporting-edge enumeration, independently solved moment constraints, a differentiated transformed primitive, truncated-power kernel construction, boundary-system equations, exact continuous-recovery integration and growth-derivative identities. The record's analytic certificate separately handles convergence, branch choices, function-class assumptions, sharpness, equality and nonattainment. None is represented as human review or formal proof.

## Meaningful finite domains and related ideas

`inventory-review.json` lists every proposed normalized capacity key. Fixed-interval pole positions, polynomial degrees, nonsimilar hulls, well degeneracies/regimes, active-support constraints, quadrature geometries, endpoint ratios and nonconvex means have explicit roles. Reflection/scalar aliases are excluded where applicable. These are proposed keys subject to the parent's independent equivalence review, not a guarantee that all 108 will be counted.

Cross-topic relations must remain visible: the three-node Peano construction shares `peano-kernel-sharp-error` with differentiation; the endpoint-energy construction is related to Sturm/Dirichlet ground-state arguments; the nonlinear uniform-bound threshold is related to Osgood comparison. These are not claimed as new global mathematical inventions.
