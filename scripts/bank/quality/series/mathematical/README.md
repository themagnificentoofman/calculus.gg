## APIs

`runtime.py` uses one persistent subprocess per frozen constructor, avoiding same-name imports.

- `catalog()` returns exact route/family/index domains.
- `build(route, family, index)` reconstructs the exact frozen option patch.
- `source(route, family, index)` returns its guarded original canonical record.
- `supports(route, record)` and `build_patch(route, record)` reject changed or unknown source records.
- `verify(route, patch, index)` checks exact reconstruction.
- `review(route, family, index)` returns the source join, independent report binding, reviewed level and normalized key.
- `presentation(route, family, index)` returns the captured current statement and explanation with its original source guard.
- `close()` closes isolated workers.

`source-joins.json` retains both the canonical source preview and, where applicable, its immutable baseline predecessor. Private-only sources use `replacesPrivateProblemId`. No new destination identity is invented. New revisions must inherit the captured current statement and explanation; historical generic prose must not be copied into a new hash and left outside the old presenter guard. Statement meaning, correct answer and exposure lineage are unchanged; options and13 difficulty labels require immutable revisions.

## Reproduction

Use Python with SymPy and Node. From this directory, write all results to a new scratch location:

```sh
python -B reproduce.py --output /absolute/new/scratch --repo /absolute/source/repository
```

`--repo` is used only to locate installed KaTeX for the648 amended fields. Omit it to run mathematical and source-bound checks without rendering. All other runtime/data dependencies are included; no machine-specific research path is required. `verify_bundle.py --output /absolute/new/result.json` is the narrower162 reconstruction/guard check. Independent proof verifiers are under `evidence/independent-code`; the originals and reports are preserved byte-for-byte.
