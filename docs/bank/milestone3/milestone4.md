# Deferred: Milestone 4

Begin free-response work in individual practice. This release retains four-option multiple choice and server-owned grading.

Future requirements:

- Keyboard-friendly visual math entry alongside raw LaTeX editing and live preview.
- Common and advanced notation, accessible labels/navigation, and usable mobile input.
- Mathematical-equivalence grading on explicit domains and branch conventions, including additive constants for indefinite integrals.
- Explicit unsupported and indeterminate outcomes; never turn numerical agreement into a proof of equivalence.
- Immutable response-format and grading-contract versions in saved question/replay snapshots.
- A separate validation, abuse, cost, and latency plan before enabling new grading paths.

The v2 pedagogy contract records `responseFormat: multiple-choice`; a future schema version can add free response without changing old snapshots. No editor or free-response grader is implemented in Milestone 3.
