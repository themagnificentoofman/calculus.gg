This read-only review covers all 72 original `original-linear-families-v2` families and their 100,800 original records. This is a limit of the reviewed evidence, not a claim that every old problem is wrong or that no bounded historical subset could ever qualify.

## What the existing evidence shows

- The general baseline screen has non-position flags for **15 families** and no threshold flags for **57**. Its 700/700 split is recorded separately for every family. All 15 flagged families also have a non-position rule reaching 62.5% in both halves.
- A separate prior rational-lattice audit finds a signal in **one additional family**, `removable-exponential-derivative`: 89.64% held-out expected accuracy, with 555 correct among 555 unique predictions. The generic screen did not flag that family.
- Thus **16 families have some documented threshold signal**, while **56 have no such signal in the reviewed existing screens**. Those 56 are unapproved; no-flag is not proof that choices are free of clues. The report retains smaller residuals, unsupported parsing and incomplete coverage.
- All **72 families have prior exact mathematical certificates and improved worked-solution evidence**. All **100,800 original content hashes** match the current historical presentation guard. The previous strict render covered four edge records per family; this report does not turn that into a complete served render claim.
- Every original menu comes from the shared answer-offset mechanism. Positive nonzero differences establish distinct values, but the constructor does not derive each wrong choice from a reviewed mathematical error. No exact old menu set was found with all current misconception, presentation and easiest-route obligations completed.
- **69 families** use three fixed kernels under a fixed linear operation. **Three special ODE families** use dedicated nonlinear or parameter-dependent constructors: `hidden-riccati`, `clairaut-envelope`, `euler-double-resonance`. The existing blanket construction description should be corrected for them.

Fixed kernels and coefficient practice are not automatically defects. The prior editorial evidence identifies useful practice in power rules, initial values, limits, series and advanced connections. That concept-level usefulness does not certify the original choices or justify counting every coefficient tuple as a new idea. Age supplies neither automatic retention nor automatic withdrawal.

## Recommended disposition

Keep the exact Experimental allowlist empty until a bounded source-bound review demonstrates a useful historical subset. The Legacy label and opt-in do not lower content standards. Families with measured signals need a concrete repair or a justified exact-menu disposition; families without flags still need the missing misconception and full current presentation/difficulty evidence. Do not select a supposedly safe subset merely by excluding cases where the already-observed predictor succeeds.

Any reviewed meaning-preserving presentation change must preserve historical source guards. Changes to choices, answer keys, difficulty or mathematical meaning need the established immutable-revision workflow. Canonical hashes, saved answers, grades, replay snapshots and exposure lineage remain historical facts. This report recommends no history mutation and performs no admission, import or publication.
